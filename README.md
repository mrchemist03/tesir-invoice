# تأثير · Tesir Invoice

تطبيق Windows محلي لإنشاء الفواتير وعروض الأسعار وسندات القبض ومحاضر الاستلام. واجهة عربية، وبيانات تبقى على جهاز المستخدم، دون حساب أو خادم.

**الحالة: نسخة أولية قيد التطوير `0.1.0-alpha.2`.** لا يوجد إصدار عام مستقر بعد.

## ما يعمل حالياً

- إنشاء المستندات وحفظ المسودات والبحث حسب العميل والرقم والنوع والحالة والتاريخ.
- ترقيم مستقل لكل نوع داخل معاملة SQLite، والتحقق من تعارض التعديلات.
- بنود وحقول وملاحظات مخصصة، وضريبة وخصم اختياريان.
- اعتماد المستند وتثبيت بيانات الشركة والقالب معه، أو نسخه كمستند جديد.
- قوالب PNG/JPEG وختم قابل للسحب وضبط مساحة الترويسة والتذييل.
- معاينة A4 وتصدير PDF متعدد الصفحات وأمر طباعة النظام.
- إعدادات الشركة وخمس عملات ذات منزلتين عشريتين، وأنواع مستندات إضافية.
- نسخة احتياطية يدوية ونسخ تلقائية عند الإغلاق، تشمل القوالب والأختام.

## العملاء والمنتجات

من القائمة الجانبية يمكنك إضافة العملاء وبيانات التواصل، وإضافة المنتجات مع الوصف والسعر والعملة والضريبة، ثم البحث عنها وتعديلها أو أرشفتها.

داخل المستند، اكتب اسم العميل أو المنتج واختر من الاقتراحات. اختيار المنتج يملأ الوصف والسعر والضريبة ويحافظ على كمية البند وخصمه. تظهر فقط المنتجات بعملة المستند.

عند حفظ المستند بنجاح، يُضاف العميل الجديد وكل منتج جديد تلقائياً. لا تحفظ الكتابة وحدها سجلات ناقصة، ولا تنتج عملية الحفظ الفاشلة سجلات إضافية. المطابقة تكون بالاسم بعد توحيد المسافات وحالة الأحرف، وبالاسم والعملة للمنتجات. تغيير السعر في فاتورة لا يحدّث سعر القائمة؛ تعديله يكون من صفحة المنتجات. يبقى المؤرشف خارج الاقتراحات حتى إلغاء أرشفته، ولا يُحذف من المستندات القديمة.

عند الانتقال من النسخة السابقة، ينشئ التطبيق نسخة احتياطية قبل ترقية مخطط SQLite إلى v2، ويستخرج قوائم أولية من المستندات السابقة دون تعديلها. عند تكرر المنتج في مستندات قديمة يستخدم أول سعر يصادفه أثناء قراءة المستندات من الأحدث إنشاءً. يمكن تعديل السعر من القائمة. لا يمكن للنسخة alpha.1 فتح قاعدة v2؛ استخدم النسخة الجديدة أو نسخة ما قبل الترقية مع النسخة القديمة.

## التشغيل من المصدر

يلزم Git وNode.js 24 أو أحدث، ويستهدف الاختبار والتوزيع Windows حالياً.

```sh
git clone https://github.com/mrchemist03/tesir-invoice.git
cd tesir-invoice
npm ci
npm run dev
```

يتطلب تثبيت الاعتماديات اتصالاً بالإنترنت. بعد التثبيت يعمل التطبيق محلياً. الواجهة تتحدث مع Electron؛ فتح عنوان Vite وحده في متصفح لا يتيح التخزين. تغييرات الواجهة تتحدث مباشرة في وضع التطوير، وتغييرات main/preload تتطلب إعادة تشغيل الأمر.

```sh
npm test
npm run format:check
npm run build
npm run test:e2e
npm start
```

إنشاء حزمة Windows أو ملف تثبيت:

```sh
npm run package:dir
npm run package
```

المخرجات داخل `release/` ومستثناة من Git. المثبّت المحلي غير موقّع رقمياً بعد، وقد يعرض Windows رسالة تحقق من الناشر.

## البيانات والنسخ الاحتياطي

قاعدة البيانات `tesir.db` داخل مجلد `userData` الخاص بـ Electron، في نسخة Windows المعبّأة: `%APPDATA%/Tesir Invoice`. النسخ التلقائية داخل `backups/` مع الاحتفاظ بآخر سبع نسخ ناجحة.

تستخدم النسخة الاحتياطية `VACUUM INTO` للحصول على ملف SQLite متسق مع WAL. القوالب والأختام مضمّنة في قاعدة البيانات، فلا تحتاج إلى جمع ملفات صور خارجية. لا تحذف ملف قاعدة البيانات أو تنسخه أثناء عمل التطبيق لاستعادته يدوياً. واجهة الاستعادة الآمنة لم تُنفذ بعد.

## الحدود الحالية

- استيراد خلفيات PDF، ومعايرة إزاحة الطابعة، وواجهة استعادة النسخ الاحتياطية ما زالت ضمن الخطة.
- المعاينة تعرض المحتوى على ورقة ممتدة؛ التقسيم النهائي للصفحات يظهر في PDF.
- الطباعة الفعلية على أجهزة مختلفة لم تُختبر بعد؛ الطباعة دون هوامش تتطلب دعم الطابعة.
- الحسابات: خصم مبلغ لكل بند ثم ضريبة على صافي البند، وتقريب نصف لأعلى لكل بند. التطبيق ليس نظام امتثال ضريبي لدولة معينة ولا يدعم دفتر قيود محاسبي.
- توقيع البرنامج والتحديثات التلقائية والنشر العام للإصدارات تأتي بعد استكمال اختبارات التوزيع.

## التفقيط التلقائي

من الإعدادات فعّل «تفعيل التفقيط تلقائياً للمستندات الجديدة». يمكن إظهاره أو إخفاؤه لكل مستند قبل اعتماده. يُحسب من الإجمالي النهائي بعد الخصم والضريبة، بعملة المستند، ويظهر في المعاينة والطباعة وPDF. تدعم العملات TRY وUSD وEUR وSAR وAED، بما فيها الصفر وأجزاء العملة. المستندات القديمة لا يتغير عرضها تلقائياً.

## استيراد المنتجات من Excel

1. افتح **المنتجات ← تحميل قالب Excel**.
2. املأ ورقة **المنتجات** من الصف الثاني، أو الصق القيم من جدول آخر. اسم المنتج وسعر الوحدة مطلوبان؛ الرمز والوصف والعملة والضريبة اختيارية. العملة الفارغة تستخدم إعداد التطبيق.
3. احفظ بصيغة **XLSX** ثم اختر **استيراد من Excel**.
4. راجع الصفوف. صحّح الأخطاء في الملف وأعد اختياره، ثم أكد استيراد المنتجات الجديدة.

الحد 5000 منتج و10 ميغابايت. يُتخطّى المنتج الموجود بالاسم والعملة، بما فيه المؤرشف، دون تغيير سعره. الصفوف المكررة داخل الملف تُتخطّى أيضاً. اكتب الأسعار دون فواصل آلاف، والضريبة مثل `20` أو `20%`. الصيغ لا تُنفّذ ولا تُستورد؛ استخدم لصق القيم فقط. يُحفظ الاستيراد دفعة واحدة بعد التحقق، ويمكن إلغاؤه قبل التأكيد.
