# Tesir Invoice

تطبيق سطح مكتب مفتوح المصدر قيد التطوير لإنشاء الفواتير وعروض الأسعار وسندات القبض ومحاضر الاستلام، مع دعم العربية والعمل محلياً دون اتصال.

> الحالة: تأسيس المشروع. لا يوجد تطبيق قابل للتشغيل أو إصدار للتنزيل بعد.

## النطاق المخطط

- محرر مستندات موحد مع أنواع وحقول مخصصة.
- قوالب ورق الشركة ومعاينة A4 والطباعة والتصدير إلى PDF.
- بيانات محلية باستخدام SQLite، مع ترحيلات ونسخ احتياطية.
- Windows أولاً، مع دراسة دعم أنظمة أخرى لاحقاً.

## التقنيات المخططة

Electron، React، TypeScript، Tailwind CSS، SQLite وelectron-builder.
