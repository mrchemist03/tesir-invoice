# تيسير · Tesir Invoice

تطبيق Windows محلي لإنشاء الفواتير وعروض الأسعار وسندات القبض ومحاضر الاستلام. واجهة عربية، وبيانات تبقى على جهاز المستخدم، دون حساب أو خادم.

**الحالة: نسخة أولية قيد التطوير `0.1.0-alpha.1`.** لا يوجد إصدار عام مستقر بعد.

## ما يعمل حالياً

- إنشاء المستندات وحفظ المسودات والبحث حسب العميل والرقم والنوع والحالة والتاريخ.
- ترقيم مستقل لكل نوع داخل معاملة SQLite، والتحقق من تعارض التعديلات.
- بنود وحقول وملاحظات مخصصة، وضريبة وخصم اختياريان.
- اعتماد المستند وتثبيت بيانات الشركة والقالب معه، أو نسخه كمستند جديد.
- قوالب PNG/JPEG وختم قابل للسحب وضبط مساحة الترويسة والتذييل.
- معاينة A4 وتصدير PDF متعدد الصفحات وأمر طباعة النظام.
- إعدادات الشركة وخمس عملات ذات منزلتين عشريتين، وأنواع مستندات إضافية.
- نسخة احتياطية يدوية ونسخ تلقائية عند الإغلاق، تشمل القوالب والأختام.

## التشغيل من المصدر

يلزم Git وNode.js 24 أو أحدث، ويستهدف الاختبار والتوزيع Windows حالياً.

```sh
git clone https://github.com/mrchemist03/tesir-invoice.git
cd tesir-invoice
npm ci
npm run dev
```

يتطلب تثبيت الاعتماديات اتصالاً بالإنترنت. بعد التثبيت يعمل التطبيق محلياً. الواجهة تتحدث مع Electron؛ فتح عنوان Vite وحده في متصفح لا يتيح التخزين. تغييرات الواجهة تتحدث مباشرة في وضع التطوير، وتغييرات main/preload تتطلب إعادة تشغيل الأمر.

```sh
npm test
npm run format:check
npm run build
npm run test:e2e
npm start
```

إنشاء حزمة Windows أو ملف تثبيت:

```sh
npm run package:dir
npm run package
```

المخرجات داخل `release/` ومستثناة من Git. المثبّت المحلي غير موقّع رقمياً بعد، وقد يعرض Windows رسالة تحقق من الناشر.

## البيانات والنسخ الاحتياطي

قاعدة البيانات `tesir.db` داخل مجلد `userData` الخاص بـ Electron، في نسخة Windows المعبّأة: `%APPDATA%/Tesir Invoice`. النسخ التلقائية داخل `backups/` مع الاحتفاظ بآخر سبع نسخ ناجحة.

تستخدم النسخة الاحتياطية `VACUUM INTO` للحصول على ملف SQLite متسق مع WAL. القوالب والأختام مضمّنة في قاعدة البيانات، فلا تحتاج إلى جمع ملفات صور خارجية. لا تحذف ملف قاعدة البيانات أو تنسخه أثناء عمل التطبيق لاستعادته يدوياً. واجهة الاستعادة الآمنة لم تُنفذ بعد.

## الحدود الحالية

- استيراد خلفيات PDF، ومعايرة إزاحة الطابعة، وواجهة استعادة النسخ الاحتياطية ما زالت ضمن الخطة.
- المعاينة تعرض المحتوى على ورقة ممتدة؛ التقسيم النهائي للصفحات يظهر في PDF.
- الطباعة الفعلية على أجهزة مختلفة لم تُختبر بعد؛ الطباعة دون هوامش تتطلب دعم الطابعة.
- الحسابات: خصم مبلغ لكل بند ثم ضريبة على صافي البند، وتقريب نصف لأعلى لكل بند. التطبيق ليس نظام امتثال ضريبي لدولة معينة ولا يدعم دفتر قيود محاسبي.
- توقيع البرنامج والتحديثات التلقائية والنشر العام للإصدارات تأتي بعد استكمال اختبارات التوزيع.
