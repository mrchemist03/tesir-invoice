# مراحل التنفيذ

المرجع التفصيلي هو [خطة العمل الأصلية](../خطة-عمل-تطبيق-المحاسبة.md). القائمة التالية تتتبع التنفيذ؛ التقديرات الزمنية في الخطة أولية.

## المرحلة التمهيدية: المستودع

- [x] إعداد ملفات التوثيق والمساهمة والأمان واستثناءات Git.
- [x] اعتماد رخصة GPL-3.0 وإضافة نصها الرسمي.
- [ ] اعتماد هوية صاحب commits.
- [ ] تسجيل أول commit وربط المستودع بـ GitHub.
- [ ] تفعيل حماية main وإعدادات الأمان على GitHub.

## المرحلة 0: الأساس

- [ ] تأسيس Electron وReact وTypeScript وTailwind.
- [ ] إعداد SQLite وmigrations واختبارها.
- [ ] إعداد فحوصات TypeScript والتنسيق والاختبارات والبناء في GitHub Actions.

## المرحلة 1: الإعدادات والقوالب

- [ ] إعدادات الشركة والعملة واللغة.
- [ ] رفع قوالب ورق الشركة وتحديد موضع الختم.

## المرحلة 2: المستندات

- [ ] محرر البنود والحقول والأعمدة الاختيارية.
- [ ] أنواع المستندات الأساسية والمخصصة.
- [ ] الحسابات والترقيم داخل معاملات تمنع التكرار.

## المرحلة 3: الطباعة والتصدير

- [ ] معاينة A4 مع خلفية القالب.
- [ ] تصدير PDF والطباعة ومعايرة الهوامش.
- [ ] اختبار المستندات المتعددة الصفحات والطابعات المتاحة.

## المرحلة 4: الاستقرار والتوزيع

- [ ] النسخ الاحتياطي والاستعادة والبحث والفلترة.
- [ ] اختبارات الاستخدام والبناء على Windows.
- [ ] تجهيز إصدار تجريبي وملف تثبيت عبر GitHub Releases.

## قرارات تُحسم قبل تنفيذ البيانات

- وضع الوصول إلى SQLite في عملية Electron الرئيسية، مع واجهة IPC محددة عبر preload.
- تحديد تمثيل دقيق للمبالغ وقواعد التقريب قبل اعتماد مخطط الجداول.
- تحديد آلية نسخ احتياطي متسقة مع SQLite تشمل أصول القوالب المطلوبة للاستعادة.
